# FoodApp (React Native)

## 📌 Project Description
FoodApp is a mobile application built using React Native.
The app displays food items, allows users to view details,
and manage a list of favorite items.

This project was developed as part of an assignment.

---

## 🧩 Features
- Home screen with food items list
- Details screen for selected food item
- Favorites screen
- Bottom Tab Navigation
- Stack Navigation
- Reusable components
